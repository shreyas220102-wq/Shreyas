# CLAT 2028 Study Companion

A responsive, static study planner for CLAT 2028. It includes:
- Five-subject daily checklist
- Date-based study notes, study time, and mood
- Subject-wise practice scores and accuracy
- Progress summary and recent study days
- Export/import JSON backup and download a daily text log

## Publish with GitHub Pages

1. Create a **public** repository (for example `clat-2028-study`).
2. Upload `index.html`, `style.css`, `script.js`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for deployment. The site will be available at `https://YOUR-USERNAME.github.io/clat-2028-study/`.

## Data and privacy

This is a static website. Study entries are saved in the current browser using local storage. They do **not** sync between devices and may be lost if browser site data is cleared. Use **Export backup** regularly and store the JSON file safely. Avoid recording sensitive personal information. The website is an independent study tool, not an official CLAT site.

## Customisation

Edit the task descriptions in `script.js` and the styling in `style.css`. Commit changes to the publishing branch to redeploy.
